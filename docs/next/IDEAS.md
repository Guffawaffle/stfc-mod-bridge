# Product ideas

These notes record ideas, not accepted implementation or release claims.

## Shuttle Bay simple mode — 2026-10-20

Guff proposed a clean mode for ordinary daily play: run/focus the game, update
the mod, and update the game. It can offer a choice between registered
installations, without exposing profile controls. Keep developing the single
launch flow. Multi-launch could become an additional, explicitly toggleable
feature. The relationship between simple/advanced presentation and multi-launch
needs a later product decision; no launch/profile behavior changes with this note.
