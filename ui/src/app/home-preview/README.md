# Development Home preview

Open `/home-preview/` with the existing UI Vite development server. This entry
mounts real `App.svelte` with one shared fixture-backed facade and key-remounts
the entire application whenever its scenario or draft outcome resets. It has
no production imports, native host, game, producer, account or release proof.
Root owns server setup, production graph checks and browser qualification.

`createHomeSession(mode, {draftOutcome})` in `mocks/home-session.ts` exports nine
strict scenario modes. Read the visible instructions before operating each
script. Ordinary uses installation A and ordinary; isolated uses installation A,
the first isolated profile (option labelled isolated 2), and existing data mode.
Focus submits session 1 from the accepted Windows fixture; remaining rows show
the accepted old/recycled PID observations. Choosing another request in these
bounded scripts fails closed through `ScenarioTransport`; it is not a policy
oracle. Every loaded raw fixture has its original byte SHA-256 displayed.

The ordinary and isolated launch scripts preserve accepted plan digests,
semantic captures and operation identities. Only observed selector revision
assertions and correlation slots change in prepare requests. Completion frames
combine accepted operation facts with generated query envelopes. Lost delivery
uses an exact same-input replay and does not imply cancellation/non-admission.
The dirty script preopens the accepted dirty revision-2 draft, synchronizes its
identical edits at that revision, and preserves the unchanged Save capture.
Its synthetic admission is derived from the accepted completed operation;
navigation is applied only after the accepted completed Save is observed.
The separate Development draft outcome selector resets between Save and exact
Discard scripts. Stay submits neither. Offline/recovery are explicit generated
reason variants, not computed native policy.

Stable accessible development controls are `Home scenario`, `Development draft
outcome`, `Reset Home scenario`, `Advance fixture time automatically`,
`Tick fixture clock`, and `Settle fixture observations`. Automatic time defaults
on so native modal busy states can finish while their background is inert.
Manual settle is bounded to 64 turns by default and never confirms a review.
Old sessions, subscriptions, client pending observations, and timers are disposed
at reset; only the current facade can project a result.

Stable browser diagnostics: `home-preview-action-state`,
`home-preview-confidence`, `home-preview-selection`, `home-preview-draft`,
`home-preview-navigation`, `home-preview-script`, `home-preview-requests`,
and `home-preview-provenance`. Normal App controls are documented in the Home
integration README. Shared fixture contents remain out of normal production UI.
